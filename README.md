# Vehicle Lighting Test Automation Framework

A C#/.NET-based simulation of an automotive lighting ECU with
automated testing capabilities.

## Project Goals

- Simulate automotive lighting behavior
- Implement lighting state transitions
- Validate operating conditions
- Implement diagnostic handling
- Provide a REST API
- Create automated tests
- Integrate testing into CI/CD

## Technologies

- C#
- .NET
- ASP.NET Core
- xUnit
- Git
- Docker
- GitHub Actions
